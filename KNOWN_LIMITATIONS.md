# Known limitations

- **Real testnet GEN, Studionet only.** Curve reserves, creator collateral, fees and floor pools are real Studionet GEN (1 accounting unit = 0.001 GEN). Buys and launches attach GEN; sells, rewards and slashes become withdrawable credits that the owner pulls with `withdraw`. No mainnet asset, financial protection or adoption is claimed. Test accounts are funded from the free Studionet faucet.
- **No seed curves.** The v2 constructor starts empty. The three seed curves shown in the local rehearsal use `origin: "seed_demo"`. Their prefilled verdicts, scores and witnesses are illustrative placeholders, not historical consensus evidence.
- **Cumulative threshold.** The gate unlocks permanently at 100 GEN of cumulative net buys. Buy fees are excluded; sells do not reduce this total. The current reserve can therefore fall below the threshold while evaluation remains available.
- **GitHub API anchoring.** The manifest is only a pointer. Validators independently fetch the tag commit SHA, the commit count and the repository tree at that SHA from the GitHub API, and require the manifest's `commit_sha` to match, the manifest count to be within the API count and at least 2, and at least 3 real code files totalling at least 1000 bytes. A tag proves code exists at a commit; it does not establish code quality, authorship or delivery authenticity.
- **Snapshot and availability.** Both manifest mirrors must identify the same repository path. When both respond, canonical contents must agree. GitHub API errors, rate limits, malformed results or unavailable sources abort the audit before writes. A moved tag or changed manifest can produce disagreement; use immutable commit URLs for repeatable snapshots.
- **Semantic scoring.** After deterministic checks, independently produced LLM scores select BOOST or GRADUATE. Scores describe semantic alignment against the fetched file tree, not an independent factual attestation. Equivalent results require the same verdict and facts, with score tolerance of 20.
- **Bounded execution (v3).** The first successful evaluation fixes a 24-hour consensus transaction-time deadline. One challenge and one permissionless review are allowed for the curve lifetime; review uses the original URLs and never extends the deadline. After expiry anyone can execute the latest successful verdict, even when review fails or the creator disappears. A challenge is an allegation, not evidence capable of overriding consensus. Permissionless execution still needs someone to submit a transaction; nothing executes automatically. Transaction time is consensus execution metadata, not the browser clock; the UI countdown is advisory. Manifest contents at the same URL may change before review; immutable URLs are recommended. Only the creator may initiate the first evaluation, so pre-evaluation creator inactivity remains outside this fix.
- **Deployment boundary.** Historical v2 addresses and receipts do not prove v3 behavior. The v3 deployment is finalized successfully; real expiry execution, repeat-execution rejection, redemption, withdrawals and final GEN conservation are verified in evidence/v3/live-verification.json. Existing v2 positions cannot be migrated by this source change.
- **Curve shape after boost.** The virtual offset preserves reserve solvency at the slope change. At low supply the reserve integral is clamped at zero. Marginal price is the unadjusted curve derivative; it can differ from an integer trade's actual reserve difference. Holder pool distributions follow current supply, rather than a snapshot of pre-audit holders.
- **Browser session account.** The temporary test account signs real Studionet transactions independently of an injected wallet. Keys exist only in session memory and are discarded on reload or closure. Public pending hashes can resume tracking, but cannot restore signing access to previous positions. There is no key export or recovery feature.
- **Commit-reveal.** Commitments hide rather than encrypt the secret. Use a high-entropy salt and keep a personal copy outside the application. Salt and secret become public transaction inputs at reveal; losing either prevents reveal.
- **Witness scope.** Witnesses preserve contradictory claims and the active verdict. They are attributed allegations, not independently verified corrections or an appeal process.
